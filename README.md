# Tan Nguyen Niên Project

Tạo 1 web tên TÂN NGUYÊN NIÊN theo yêu cầu và mô tả, Về mặt thẩm mỹ, mình hình dung TÂN NGUYÊN NIÊN với nền đen/xám than, chữ trắng lạnh, các đường giao diện mảnh, hiệu ứng scanline rất nhẹ, typography mang cảm giác quân sự tương lai. Màu nhấn có thể dùng một tông trắng bạc hoặc xanh băng, trong khi cảnh báo Trùng tộc mới chuyển sang một màu tương phản. Không nên dùng quá nhiều hiệu ứng neon vì sẽ làm mất chất “tinh tế” mà bối cảnh đang có. Sử dụng font việt hóa miễn phí./skill:redesign
